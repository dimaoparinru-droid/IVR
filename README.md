Сайт, на котором юзер может зарегестрироваться, указать цель визита к врачу, его специальность, выбрать нужные даты и устраивающий его временной интервал, указать приоритное время (для случая если подходящих записей несколько. Приоритеты: самое раннее/позднее время из доступных), выбрать, нужно ли сразу оформить запись или просто прислать уведомление. Когда подходящая по параметрам запись будет доступна, сайт пришлёт уведомление (и оформится запись, если нужно). В сущности сайт будет почти полностью копировать процедуру оформления записи в самом емиасе, за исключением последнего этапа выбора временного интервала. Также будут функции для записи на уже выложенные слоты, их просмотра и отмены.
